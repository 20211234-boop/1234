# Image to Code — 이미지를 웹페이지로

## 절차

1. **이미지 분석.** 코드를 쓰기 전에 짧게 정리한다.
   - 구역 순서(머리글, 히어로, 본문 섹션, 바닥글)와 각 구역의 배치(열 개수, 정렬)
   - 색: 배경·본문 글자·강조색을 hex로 추정
   - 글자: 제목/본문 크기 단계, 굵기, 세리프 여부
   - 간격 단위(8px 배수 등), 모서리 반경, 그림자 유무
2. **형식 정하기.** 저장소에 프레임워크(React, Vue, Tailwind 등)가 있으면 그 방식을 따른다. 없으면 HTML 파일 하나에 CSS를 함께 쓴다.
3. **구현.**
   - 색·간격·글자 크기는 CSS 변수로 먼저 정의한다.
   - 이미지 속 실제 문구를 그대로 옮긴다. 읽을 수 없는 부분만 자리표시 문구를 쓰고 사용자에게 알린다.
   - 사진·아이콘 자리는 같은 크기의 회색 상자나 기본 아이콘으로 두고, 무엇이 들어갈 자리인지 주석을 단다.
   - 모바일 폭(약 375px)에서도 무너지지 않게 만든다.
4. **비교 검증.** 브라우저(Playwright, agent-browser 등)를 쓸 수 있으면 결과를 같은 크기로 캡처해 원본과 나란히 비교하고,
   다른 점(간격, 크기, 색, 줄바꿈)을 고친다. 2회 반복 후에도 남은 차이는 목록으로 알린다.
   브라우저가 없으면 확인하지 못했다고 말한다.

## 지켜야 할 것

- 다른 회사의 실제 사이트를 그대로 복제해 그 회사처럼 보이게 만들지 않는다. 로고·상표는 넣지 않는다.
- 원본 이미지에 없는 기능이나 섹션을 덧붙이지 않는다.
