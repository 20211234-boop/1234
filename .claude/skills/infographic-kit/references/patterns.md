# 도식 패턴과 반복 피하기

## 어떤 도식을 쓸까

| 내용 | 도식 | 템플릿 부품 |
|---|---|---|
| 방식 여러 개를 단계별로 비교 (예: 수작업 / 자동화 / AI) | **레인**: 왼쪽 색 블록 + 오른쪽 가로 흐름 | `.lane` `.lane-label` `.flow` `.node` `.arrow` |
| 둘·셋을 나란히 비교 | **비교 열**: 머리 띠 + 세로 점선 흐름 + 하단 "이럴 때" 상자 | `.vs` `.vs-col` `.vs-head` `.down` `.best` |
| 순서가 있는 절차 | **번호 흐름**: 단계 배지 + 노드 | `.step` `.node` `.arrow` |
| 반복되는 과정 (계획 → 실행 → 확인) | **그룹 상자**: 점선 테두리 + 알약 제목 "반복" | `.group` `.pill` |
| 갈림길·승인·차단 | **마름모 판정** + 빨간 화살표 + 결과 꼬리표 | `.gate` `.arrow.red` `.tag` |
| 데이터·규정 저장소 | **원통** | `.db` |
| 검사 항목 여러 개 + 실패 시 처리 | **번호 격자** (2~3열 상자, 각 상자 옆 점선 → 노란 꼬리표) | `.step` + 상자 + `.tag` |
| 핵심 수치 몇 개 | **통계 카드** (제목 + 큰 숫자 + 증감) | `.cards` `.stat` |
| 비율 하나 | **도넛** | `.donut` (`--p`에 백분율) |
| 구성 요소 설명 (기억·도구·판단·안전장치 등) | **구역 지도**: 색 다른 점선 구역 4개 + 가운데 원 + 구역 사이 화살표 | `.group` 여러 개 + `--c1`~`--c4` |

## 반복 검사 (내보내기 전 6개)

1. **같은 아이콘이 다른 뜻으로 두 번 쓰였는가?** → 같은 뜻일 때만 같은 아이콘. 나머지는 `icons.py pick`으로 다시 고른다.
2. **노드 틀이 전부 같은가?** → 틀 4종(`frame-box`, `frame-soft`, `frame-ring`, `frame-plain`)을 의미에 따라 나눈다.
   예: 사람·주체는 `ring`, 시스템·도구는 `box`, 결과물은 `soft`, 목표·시작점은 `plain`.
3. **모든 연결선이 같은가?** → 정상 흐름은 회색 점선, 위험·차단은 빨간 점선(`.arrow.red`), 되돌아가는 흐름은 위쪽에 따로 그린다.
   화살표 위 설명(`data-label`)은 흐름이 바뀌는 곳에만 붙인다.
4. **한 화면에 같은 도식 형태가 2개 이상 연달아 있는가?** → 두 번째는 다른 형태(비교 열, 카드, 번호 격자)로 바꾼다.
5. **아이콘이 글자를 대신하고 있는가?** → 아이콘은 글자를 돕는 것. 모든 노드에 글자 이름을 붙인다.
6. **색이 4개를 넘는가?** → 레인 색 4개 + 경고(빨강) + 강조(노랑)까지만. 아이콘 색은 그 레인 색을 따른다.

## 크기 기준

| 요소 | 크기 |
|---|---|
| 노드 아이콘 | 22px (틀 안), 34px (`frame-plain`) |
| 카드 아이콘 | 20~22px |
| 슬라이드용 단독 아이콘 | 64~96px, 선 굵기 1.5 |
| 화살표 최소 길이 | 48px (짧으면 설명 글자가 겹친다) |
| 레인 왼쪽 블록 폭 | 120px, 글자 18px 굵게 |

## 한국어 아이콘 키워드

`assets/ko-keywords.json`에 없는 단어는 영어로 바꿔 `icons.py search`에 넣는다.
자주 쓰는 영어 검색어: approval, calendar, chart, check, clock, document, money, people, security, settings, warning.
새 단어를 자주 쓰게 되면 `ko-keywords.json`에 추가한다 (값은 반드시 `icons.json`에 있는 이름).
