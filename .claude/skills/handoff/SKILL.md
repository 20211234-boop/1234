# Handoff — 인수인계 요약

컨텍스트를 비우기 전에, 다음 세션이 이 파일 하나만 읽고 바로 이어서 작업할 수 있게 정리한다.

## 절차

1. 대화 전체를 돌아보고 아래 항목을 뽑는다. 추측하지 말고 실제로 한 일만 적는다.
2. `git status`와 `git diff --stat`으로 수정한 파일 목록을 확인해 대조한다.
3. 프로젝트 루트의 `HANDOFF.md`에 아래 형식으로 쓴다. 이미 있으면 덮어쓴다.
4. 사용자에게 다음 안내만 짧게 한다:
   > 정리 완료. `/clear` 후 "HANDOFF.md 읽고 이어서 해줘"라고 입력하세요.

## HANDOFF.md 형식

```markdown
# Handoff — <날짜>

## 목표
<이 작업이 무엇을 하려는지 1~2줄>

## 결정 사항
- <결정> — <이유>

## 수정한 파일
- `path/to/file` — <무엇을 바꿨는지 한 줄>

## 현재 상태
- 완료: ...
- 테스트: <마지막 실행 결과>

## 다음 할 일
1. ...

## 주의할 점
- <알려진 버그, 막힌 부분, 하지 말아야 할 것>
```

## 규칙

- 탐색 과정, 도구 출력 원문, 이미 해결된 시행착오는 적지 않는다.
- 짧게 쓴다. 전체가 한 화면을 넘지 않게 한다.
- 커밋되지 않은 변경이 있으면 "주의할 점"에 적는다.
