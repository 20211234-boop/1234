## 1단계. 자료 모으기 (약 30분)

| 시트 | 필요한 자료 | 어디서 |
|---|---|---|
| 월별실적 | 1월~마감월 월별 기본급·제수당·초과근무수당·상여 합계, 월말 인원 | 급여시스템 급여대장(월별 집계) |
| 월별실적 | 4대보험 회사부담분 | 4대보험 고지서 또는 급여시스템 |
| 월별실적 | 복리후생비 | 회계 복리후생비 계정 |
| 월별실적 | 전년 같은 달 인건비 합계 | 2025년 급여대장 |
| 사업계획 | 2026 월별 인건비 예산, 월별 계획 인원(TO), 계획 상여 | 재무팀 사업계획 파일, 인력계획 |
| 부서별 | 부서별 인원, 누적 인건비, 누적 계획, 연간 계획, 누적 초과근무수당 | 급여대장 부서별 집계, 부서별 사업계획 |

먼저 재무팀과 정할 것:
- 인건비에 퇴직급여 충당금을 넣는가 (양식은 **제외** 기준)
- 사업계획 인건비 예산이 양식과 같은 항목 범위인가

## 2단계. 양식 채우기

1. `인건비_대시보드_입력양식.xlsx`를 열고 각 시트의 샘플 숫자를 실제 값으로 덮어씁니다.
2. 시트 이름과 열 이름은 바꾸지 않습니다. 열 순서는 바뀌어도 됩니다.
3. 금액은 백만원 단위가 기본입니다. 원 단위로 넣어도 자동으로 바뀝니다.
4. 월별실적은 1월부터 마감월까지 빠짐없이, 사업계획은 1~12월 12행 모두 채웁니다.
5. 머리글 칸에 마우스를 올리면 칸별 설명(메모)이 보입니다.

## 3단계. 대시보드에 넣기

1. 대시보드 링크를 엽니다.
2. 오른쪽 위 **실제 데이터 불러오기**를 누르거나, 엑셀 파일을 화면에 끌어다 놓습니다.
3. 위쪽 상자가 초록색으로 바뀌고 "1~N월 실적, 부서 N곳"이 나오면 성공입니다. 빨간색이면 고칠 점이 목록으로 나옵니다.
4. 파일은 브라우저 안에서만 읽히고 어디에도 저장되지 않습니다. 새로고침하면 샘플로 돌아가므로, 볼 때마다 다시 넣어야 합니다.

## 4단계. 확인할 숫자 (5분)

- [ ] 상단 누적 인건비가 급여대장 누적 합계와 같은가
- [ ] 사업계획 대비 집행률이 재무팀 숫자와 같은가
- [ ] 연말 착지 전망 방식(최근 3개월 1인당 단가 × 예상 인원, 월 2명 증가 가정)이 회사 방식과 맞는가
- [ ] 2027 시뮬레이션의 4대보험 요율이 확정 요율과 맞는가

맞지 않으면 Claude에게 계산 방식을 바꿔 달라고 요청하면 됩니다.

## 회사 PC에서 미리 해 두면 좋은 연결

claude.ai → 설정 → 커넥터(https://claude.ai/customize/connectors) 에서:

| 커넥터 | 지금 상태 | 연결하면 |
|---|---|---|
| Google Sheets | 연결 미완료 | 사업계획 시트를 엑셀 없이 바로 읽을 수 있음 |
| Slack | 연결 미완료 | 월간 인건비 요약을 채널에 올릴 수 있음 |
| Microsoft 365 | 연결 미완료 | OneDrive·SharePoint의 엑셀을 바로 읽을 수 있음 |
| Notion | 연결 미완료 | 회의록·보고서와 연결 |
| Canva | 연결됨, 브랜드 키트 비어 있음 | 브랜드 키트에 회사 로고·색을 넣으면 대시보드 색을 회사 CI로 바꿀 수 있음 |
| GPT / OpenAI | 커넥터 목록에 없음 | 커넥터 화면에서 직접 추가해야 함 |

커넥터를 연결한 뒤에는 **새 세션**을 열어야 반영됩니다.

## 보안 메모

- 대시보드 링크 자체에는 실제 급여 숫자가 저장되지 않습니다. 숫자는 엑셀을 넣은 사람의 화면에만 보입니다.
- 링크는 비공개입니다. 팀원과 보려면 화면의 Share 메뉴에서 공유하세요. 공유받은 사람도 엑셀을 넣어야 실제 숫자를 봅니다.
- 입력양식 엑셀에는 실제 급여 정보가 들어가므로 사내 보안 폴더에만 보관하세요.
