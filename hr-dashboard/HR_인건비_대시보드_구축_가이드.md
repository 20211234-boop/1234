## HR 대시보드 후보

인원 현황은 이미 있으므로 다음은 입·퇴사, 근태·연차 순서가 좋습니다. 인건비는 시안이 완성됐습니다.

| 우선순위 | 대시보드 | 핵심 지표 | 이유 |
| --- | --- | --- | --- |
| 1 | 입·퇴사 / 이직률 | 월별 입·퇴사, 이직률, 1년 내 조기퇴사율, 퇴사 사유 | 인원 현황 데이터를 그대로 쓸 수 있음 |
| 1 | 근태 / 근로시간 | 주 52시간 초과 위험자, 부서별 초과근무, 야간·휴일근로 | 근로기준법 리스크, 근로감독 대응 |
| 1 | 연차 사용 | 사용률, 미사용 잔여일수, 연차촉진 대상자 | 연말 미사용수당 예측 |
| 2 | **인건비 (완성)** | 누적 인건비, 사업계획 집행률, 1인당 인건비, 연말 착지 | 경영진 의사결정, 사업계획 수립 |
| 2 | 채용 파이프라인 | 오픈 포지션, 단계별 전환율, 채용 소요일 | ATS나 채용 시트 필요 |
| 2 | 인력 구조 | 연령·근속 분포, 직급 피라미드, 정년 도래자 | 인원 현황의 확장판 |
| 3 | 평가 / 보상 | 등급 분포, 등급별 인상률, 보상 밴드 위치 | 평가 데이터 누적 후 |
| 3 | 교육 / HRD | 1인당 교육시간·비용, 법정의무교육 이수율 | 데이터 누적 후 |
| 3 | 퇴사 위험 / 리텐션 | 핵심인재 퇴사 위험 신호, 근속 구간별 퇴사율 | 여러 데이터 결합 필요 |

## 인건비 대시보드 화면 구성

화면은 실적 → 사업계획 대비 → 내년 예산 순서의 세 섹션입니다. 상단 기간 버튼(연초~마감월, 분기, 최근월)을 누르면 전체가 다시 계산됩니다.

| 섹션 | 칸 | 보여 주는 것 |
| --- | --- | --- |
| 01 실적 현황 | 누적 인건비 (대표 칸) | 누적 금액, 전년 대비, 실적·사업계획·전년 누적 추이 |
| 01 실적 현황 | 사업계획 대비 집행률 | 링 게이지, 실적·계획·차액 |
| 01 실적 현황 | 1인당 월평균 / 초과근무 비중 | 미니 추이 그래프, 관리 기준 5% |
| 01 실적 현황 | 인건비 구성 / 살펴볼 점 | 도넛 차트(고정비 비중), 자동 작성 인사이트 |
| 01 실적 현황 | 월별 구성 / 부서별 집행 / 트리맵 / 히트맵 | 항목별 누적 막대, 부서 집행률, 부서 규모, 부서×월 초과근무 |
| 02 사업계획 대비 | 연말 착지 전망 | 연간 계획 vs 실적+남은 달 전망 |
| 02 사업계획 대비 | 예산 소진 속도 | 기간 경과율 vs 예산 소진율, 남은 달 가용액 |
| 02 사업계획 대비 | 차이 원인 폭포 차트 | 계획 → 인원 효과 → 단가 효과 → 초과근무 → 실적 |
| 02 사업계획 대비 | 인원 계획(TO) vs 실제 / 부서별 전망 | 채용 지연 폭, 부서별 '계획 이내 / 관리 필요 / 추경 검토' |
| 03 2027 예산 시뮬레이션 | 가정 5개 슬라이더 | 임금 인상률, 순증원, 초과근무 절감, 상여 지급률, 복리후생비 증가 |
| 03 2027 예산 시뮬레이션 | 예산안 결과 | 총액, 2026 착지 대비 증감률, 항목별 표 |

계산 가정 (회사 방식과 다르면 바꿀 것):

- 남은 달 전망 = 최근 3개월 1인당 월 인건비 × 예상 인원(월 2명 증가)
- 사업계획에 초과근무 금액이 없으면 상여 제외 계획 인건비의 4.5%
- 4대보험 회사부담률 = 2026년 실적 비율 (2027 요율 확정 후 수정)
- 인건비 범위에서 퇴직급여 충당금 제외

## 디자인 원칙

2026년 대시보드 사례를 조사해 다섯 가지 원칙을 적용했습니다.

1. 벤토 그리드: 칸 크기가 중요도를 나타내게 한다. 가장 큰 칸은 누적 인건비.
2. 핵심 지표는 3~5개만, 각 카드에 지표 하나와 이전 기간 대비 변화.
3. 색은 의미에만: 주의는 코랄, 위험은 빨강, 양호는 민트.
4. 자동 인사이트 목록으로 '무엇을 봐야 하는지'를 문장으로 알려 준다.
5. 상세(표, 정의)는 접어 두고 필요할 때 펼친다.

## 글래스 버전과 모션

글래스 버전은 따뜻한 배경 위에 반투명 유리 카드를 겹친 디자인(글래스모피즘)에 모션을 더한 것입니다. 기능은 기본 버전과 같습니다.

| 요소 | 동작 |
| --- | --- |
| 인트로 | 화면을 열면 흐림에서 초점이 맞춰지며 나타나고, 카드가 순서대로 떠오름 (2초 안에 완료) |
| 숫자 카운트업 | 누적 인건비, 1인당 인건비, 초과근무 비중, 연말 전망, 2027 예산안이 0부터 올라감. 기간·슬라이더를 바꾸면 이전 값에서 새 값으로 바뀜 |
| 집행률 링 | 링이 차오르고 둘레를 6개 부서 배지가 천천히 회전 |
| 사이드바 | '<' 버튼으로 아이콘만 남기고 접힘. 상태는 브라우저에 기억 |
| 카드 호버 | 살짝 떠오르고 마우스를 따라 유리 반사광이 움직임 |
| 바로가기 3개 | 사업계획 대비 점검, 예산 초과 부서, 2027 예산 짜기. 누르면 해당 섹션으로 이동하며 강조 |
| 인사말·일정 카드 | 시간대별 인사말, 다가오는 인사·급여 일정 D-day (날짜는 예시: 10일 4대보험·원천세, 20일 급여 마감, 25일 급여 지급, 30일 사업계획 제출) |
| 배경 | 따뜻한 빛이 40초 주기로 천천히 흐름 |

운영체제에서 '동작 줄이기'를 켠 사람에게는 모션 없이 완성된 화면이 바로 보입니다.

## 회사에서 시작하기

1. **자료 모으기 (약 30분)**: 급여대장 월별 집계, 4대보험 회사부담분, 복리후생비, 전년 같은 달 합계, 재무팀 사업계획(월별 예산·계획 인원), 부서별 집계.
2. **재무팀과 기준 맞추기**: 퇴직급여 충당금 포함 여부, 사업계획 예산의 항목 범위.
3. **양식 채우기**: 시트 이름과 열 이름은 그대로, 금액은 백만원(원 단위도 자동 변환), 월별실적은 1월부터 마감월까지, 사업계획은 12행 모두.
4. **대시보드에 넣기**: '실제 데이터 불러오기'를 누르거나 엑셀을 화면에 끌어다 놓기. 초록 상자면 성공, 빨간 상자면 고칠 점이 목록으로 나옴.

확인할 숫자:

- [ ] 누적 인건비가 급여대장 누적 합계와 같은가
- [ ] 사업계획 집행률이 재무팀 숫자와 같은가
- [ ] 연말 착지 전망 방식이 회사 방식과 맞는가
- [ ] 2027 시뮬레이션의 4대보험 요율이 확정 요율과 맞는가
