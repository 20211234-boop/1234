# 작업카드 TC-HR-ATT-001 — 근태 휴가유형(반차·반반차·시간차) 설정 상태 점검

| 항목 | 내용 |
|---|---|

## 1. 목적

다음 3개 휴가유형에 대해 **설치 여부**와 **개방(오픈) 여부**를 구분하여 판정한다.

| 품목 | 기대 상태 (작업 요청자 진술) |
|---|---|
| 반차 (0.5일) | 설치 + 개방 |
| 반반차 (0.25일) | 설치 여부 미상, 미개방 |
| 시간차 (시간 단위) | 설치 여부 미상, 미개방 |

---

> ⚠️ **경고 (WARNING)**
> 점검 중 어떤 설정 화면에서도 **[저장] [적용] [사용여부 변경]을 누르지 않는다.** 실수로 개방되면 전 직원 신청 화면에 즉시 노출된다.

> ⚠️ **경고 (WARNING)**
> HAR 파일에는 **로그인 세션 쿠키와 직원 개인정보**가 들어 있다. 작업자 PC 밖으로 반출하지 않는다. 메일·메신저·GitHub 업로드 금지. 작업이 끝나면 즉시 삭제한다 (7-3항).

> 🔶 **주의 (CAUTION)**
> 캡처 시작 전 브라우저의 다른 탭을 모두 닫는다. 다른 사이트 트래픽이 섞이면 판정이 오염된다.

> ℹ️ **참고 (NOTE)**
> "설치됨"은 시스템에 해당 휴가 코드와 차감 규칙이 존재하는 상태이다. "개방됨"은 직원 신청 화면에 선택지로 노출되는 상태이다. 두 가지를 반드시 분리해서 판정한다.

## 3. 트래픽 채취 (HAR 캡처)

| 단계 | 작업 | 확인 |
|---|---|---|
| 3-1 | `F12` → **Network** 탭 → **Preserve log** 체크 → 🚫 버튼으로 기존 기록을 비운다. | ☐ |
| 3-2 | **관리자 화면**: 근태관리 → 기준(기초)설정 → 휴가/근태 유형 관리 화면을 연다. 목록을 끝까지 스크롤하고 **조회만** 한다. | ☐ |
| 3-3 | **직원 화면**: 신청결재 → 근태(휴가) 신청 화면을 연다. 휴가 종류 드롭다운을 **펼치기만** 하고 신청은 하지 않는다. | ☐ |
| 3-4 | Network 탭에서 ⬇ (Export HAR) → `C:\work\att-check\att.har`로 저장한다. | ☐ |

> ℹ️ **참고**
> 3-2의 메뉴 이름은 공급사 버전마다 다를 수 있다. "휴가코드", "근태코드", "근태항목" 같은 이름을 찾는다.

## 4. REA 분석 지시

Claude Code에서 아래 지시문을 **그대로** 입력한다.

```
/reverse-engineer-anything
C:\work\att-check\att.har 를 inspect_web_network_capture로 분석해줘. 조회만 하고 사이트에 요청은 보내지 마.

목표: 휴가유형 3종(반차, 반반차, 시간차)의 "설치 여부"와 "개방 여부"를 따로 판정.

1. 휴가/근태 코드 목록을 돌려주는 API를 찾아 엔드포인트와 응답 필드 구조를 정리
2. 응답에서 반차·반반차·시간차에 해당하는 항목을 찾아 코드값, 이름, 차감 단위(0.5 / 0.25 / 시간),
   사용여부(USE_YN 등), 신청화면 노출 여부 필드를 표로 정리
3. 관리자 화면 응답과 직원 신청화면 응답을 비교해서, 관리자에는 있는데 직원 화면에는 없는 항목을 표시
4. 같이 받은 JS 파일에서 "반반차", "시간차", "0.25", "QUARTER", "HOUR", "TIME_OFF" 문자열 검색 → 화면 로직이 이미 들어 있는지 확인
5. 결론마다 근거(어느 요청의 어느 필드인지)를 붙이고, 확인 못 한 것은 "미확인"으로 표시
6. 결과에 직원 이름·사번·쿠키값은 적지 마
```

## 5. 판정 기준 (ACCEPT / REJECT 표)

| 관측 결과 | 판정 |
|---|---|
| 코드 있음 + 사용여부 Y + 직원 신청화면에 노출 | **설치·개방 (ACTIVE)** |
| 코드 있음 + (사용여부 N **또는** 직원 화면 미노출) | **설치·미개방 (INSTALLED / STANDBY)** |
| 코드 없음 + JS에 화면 로직 있음 | **기능 탑재·코드 미등록 (PROVISIONED)** — 관리자 화면에서 코드만 등록하면 됨 |
| 코드 없음 + JS에도 흔적 없음 | **미설치 (NOT INSTALLED)** — 공급사 추가 개발 또는 모듈 활성화 필요 |
| 응답이 캡처에 없음 | **판정 불가 (INCONCLUSIVE)** — 3항부터 다시 수행 |

**정상 기대값:** 반차 = ACTIVE / 반반차·시간차 = INSTALLED 또는 PROVISIONED
→ 기대값과 다르면 **결함(DISCREPANCY)**으로 기록하고 8항에 따른다.
